# P0 公开语料核实指南

本文说明已经准备的公开录音如何听音核实。覆盖和标注要求由 [P0 Spec](specs/runtime-and-corpus-baseline.md#语料与标注)维护，本文不改变验收条件。

## 核实过程

1. 逐个播放样本，同时对照清单中的 `reference_text`。根据录音修正正文；不要根据模型输出修正文。
2. 在支持采样位置的音频编辑器中核对语音首尾。`speech_intervals` 使用 16 kHz 标准文件的半开区间 `[start,end)`，不要填写秒数或原始录音位置。
3. 为 C01 样本填写可定位的 `speaker_id`，确认至少两位不同说话人。当前 `unverified-gender-group-*` 是占位标记，不能作为正式身份。
4. 核对增广参数与人工修正后的母录音语音起点。若 C03 的衰减区间不再符合起点要求，或尾块裁掉正文，应重建受影响样本并重新听音。修正标注不能掩盖不合要求的音频。
5. 核实某个样本后，将其 `annotation_checked` 改为 `true`。建议保存 `reviewer`、`reviewed_at` 和边界核实工具名称，便于定位核实依据。
6. 更新 `corpus_version`，并保留原版本结果。若音频文件改变，重新计算 `audio_sha256`；原始素材改变还应更新来源记录。旧评分不能自动用于新版本。
7. 全部核实后，执行 README 中不带 `--exploratory` 的语料校验及完整矩阵。机器校验通过不代替前六步。

正文、边界、说话人和增广样本全部完成核实前，不运行正式质量评分，也不将 P0 标为完成。
